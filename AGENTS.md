# Instrucciones para OpenAI Codex

- Antes de modificar el proyecto, lee `docs/ai/WORKFLOW.md` y respeta sus reglas. Es la fuente maestra del workflow compartido.
- Identifica el operador, el agente y la tarea. No asumas un responsable si no está definido.
- Revisa la rama y `git status` antes de comenzar; revisa el diff y `git status` al terminar.
- Identifica los archivos afectados y su objetivo antes de editar.
- No ejecutes commit, acciones Git remotas, merge ni acciones de producción sin autorización explícita para la acción correspondiente.
- Entrega el resultado usando `docs/ai/HANDOFF_TEMPLATE.md`.
